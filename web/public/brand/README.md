# PostHog brand assets

Reference: https://brand.posthog.com/ (checked November 12, 2026).

The fonts, logo geometry, and research hedgehog come from the official
`@posthog/brand` 0.8.0 package in the local PostHog website checkout.
The SVG logos are static exports of its `Logo` component. The navigation
icons are static exports from `@posthog/icons` in that checkout.
These files are bundled so the local app does not need a CDN.

RoundHog uses the package's weight mapping: Regular 400, Medium 500,
SemiBold 700. The white landscape logo is the approved treatment for
dark backgrounds. The full-color logomark is used only for the favicon.
