# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js App Router with React and TypeScript.

## Users

Outdoor shoppers use the storefront to plan a short trip and buy durable gear. Evaluation agents use the codebase to install and verify PostHog.

## Product purpose

Northstar Supply is a realistic commerce fixture. It provides routes, client state, forms, APIs, and user journeys that require deliberate product instrumentation.

## Operating context

Shoppers browse equipment, filter products, open product details, manage a persistent trip kit, complete checkout, update account preferences, and subscribe to field notes.

## Capabilities and constraints

The app must build without external services or credentials. It stores the cart in the browser and uses local API routes for form validation. PostHog is not installed in the starting fixture.

## Brand commitments

Keep the Northstar Supply name, direct field-guide voice, and practical outdoor equipment focus.

## Evidence on hand

All product, price, stock, and journal content is synthetic evaluation data.

## Product principles

- Make each action clear and measurable.
- Keep the fixture realistic without requiring a database.
- Give agents multiple routes and client/server boundaries to instrument.
- Keep the shopper in control of the cart and preferences.

## Accessibility & inclusion

Use semantic HTML, visible keyboard focus, descriptive labels, and reduced-motion support.
